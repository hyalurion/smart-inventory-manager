# 2026-08-10

## 修复：启用 R8 后"采购清单显示无记录"
- 现象：开启 R8 全模式 + minify 后，采购清单页显示失败/无记录；库存清单正常。
- 根因：`PurchaseListViewModel` 直接调 `inventoryApiService.getPurchaseList()`（真实接口，AppModule 注入 `ApiFactory.create()` 非 mock），返回 `PurchaseListResponse` / `PurchaseListItem`。这两个模型在独立包 **`com.smartinventory.models`** 下，而 `proguard-rules.pro` 只 keep 了 `com.chronie.inventorymanager.data.**` 和 `domain.**`。模型字段（`success`/`data`/`error`/`id`/`name`/`category`/`unit` 等）大多**无 `@SerializedName`**，Gson 靠字段名反射取值；R8 全模式把字段名混淆成 `a/b/c` → JSON 映射不上 → `success` 取默认 false、`data` 取 null → 走 Error/Empty 分支。库存清单正常是因为其模型在 `domain.model`（已被 keep）。
- 修复：`proguard-rules.pro` 新增 `-keep class com.smartinventory.** { *; }`。库存/统计/采购清单现在均被覆盖。
- 经验：凡 Gson 反射反序列化且字段无 `@SerializedName` 的模型，其所在包必须整体 keep；跨包（如 `com.smartinventory`）极易漏掉。后续新增后端模型前先确认包被 keep，或统一给字段加 `@SerializedName` 并改用 `-keepattributes` + 带 SerializedName 的反射安全写法。

## 修复：状态栏文字深浅模式始终为白色（看不清）
- 现象：浅色/深色模式下状态栏图标文字始终是白色，浅色模式白字压在浅色 TopAppBar 上几乎不可见。
- 根因：① `AndroidManifest` 主题 `android:Theme.Material.Light.NoActionBar` 是浅色窗口主题，其默认 `statusBarColor` 偏深，系统据此画白色状态栏文字；② `MainActivity` 把 `androidx.activity.enableEdgeToEdge` import 了却**从未调用**；③ `SmartInventoryManagerTheme` 用 `isSystemInDarkTheme()` 切深浅，但从不把深浅状态回写系统状态栏外观，导致状态栏图标颜色恒为白。
- 修复（标准 Compose edge-to-edge 方案）：
  1. `MainActivity.onCreate` 在 `super.onCreate` 后调用 `enableEdgeToEdge()`，使状态栏透明、显示 App 顶部栏背景。
  2. `ui/theme/Theme.kt` 在 `SmartInventoryManagerTheme` 内用 `SideEffect` 设 `WindowCompat.getInsetsController(window, view).isAppearanceLightStatusBars = !darkTheme`（浅色→深字、深色→白字，与顶部栏对比正确）。需 import `android.app.Activity` / `androidx.compose.runtime.SideEffect` / `androidx.compose.ui.platform.LocalView` / `androidx.core.view.WindowCompat`。
  3. `MainActivity` 悬浮底栏 Box 加 `navigationBarsPadding()`，避免 edge-to-edge 后压到系统导航条（`androidx.compose.foundation.layout.navigationBarsPadding`）。
- 注意：本环境无 Gradle，靠用户 Build 真机验证。若某些 ROM 仍异常，可检查是否需同时设 `window.statusBarColor`。
