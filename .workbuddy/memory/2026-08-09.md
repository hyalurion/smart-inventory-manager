# 2026-08-09

## Fixed Android build (`./gradlew assembleDebug` now BUILD SUCCESSFUL)

Root causes and fixes:

1. **Broken/unused plugin declarations in Gradle version catalog** (`android/gradle/libs.versions.toml`) and root `android/build.gradle.kts`:
   - `kotlin-ksp` plugin id was wrong: `org.google.ksp` (should be `com.google.devtools.ksp`). KSP is never applied (only `apply false`), so removed the declaration.
   - `hilt-android` plugin (`com.google.dagger.hilt.android:2.59.2`) failed to resolve and is also never applied. Removed the `apply false` declaration.
   - Hilt/Room Kapt are intentionally disabled in `app/build.gradle.kts` (commented out); `InventoryItem` is a Room `@Entity` but there are NO `@Dao`/`@Database`/`@Hilt*` usages, so no annotation processing is required.
2. **Dead corporate proxy** in global `~/.gradle/gradle.properties`: `systemProp.https.proxyHost=192.168.10.13:8080` timed out and blocked all dependency downloads (masked as "plugin not found"). Direct internet works, so the 4 proxy lines were commented out (reversible).

Result: `app/build/outputs/apk/debug/app-debug.apk` produced (69.5 MB). Build needs JDK 21+ — use Android Studio JBR at `C:\Program Files\Android\Android Studio\jbr` (set JAVA_HOME). SDK platform 36 + build-tools 36.0.0 already installed.
